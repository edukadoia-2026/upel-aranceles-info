Política de privacidad

Esta política describe el tratamiento de información por SistemaArancelesUPEL y su integración con Google Drive.

Información utilizada

La aplicación procesa datos de identificación, contacto y solicitudes de aranceles para gestionar trámites y generar documentos. La autorización de Google se utiliza para acceder a los archivos habilitados para la aplicación mediante el permiso drive.file.

Uso y almacenamiento

Los registros administrativos se almacenan en la base de datos del sistema. Los documentos PDF se cargan a la cuenta de Google Drive autorizada. Los tokens OAuth se almacenan localmente en el equipo que ejecuta la aplicación.

Compartición de información

Los documentos generados pueden compartirse mediante enlaces de Google Drive accesibles a quienes posean el enlace. El servicio de SMS recibe el número de destino y el contenido necesario para transmitir la notificación. Los datos de Google se utilizan para las funciones descritas, no para publicidad ni para entrenar modelos de inteligencia artificial.

Datos de Google

El uso y la transferencia a otras aplicaciones de información recibida de las API de Google se ajustarán a la Política de datos de usuario de los servicios de API de Google, incluidos sus requisitos de uso limitado.

Revocación y solicitudes

El titular de la cuenta puede revocar la autorización desde las conexiones de su cuenta de Google. Para solicitar información, rectificación o eliminación de datos, escriba a edukado.ia@gmail.com. La conservación y eliminación de registros administrativos deberá ajustarse a las obligaciones institucionales aplicables.
